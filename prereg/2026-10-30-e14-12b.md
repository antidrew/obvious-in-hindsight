# E14: is the 12B fast enough and good enough to buy attempts? (paradigm P2)

Written 2026-10-30, before any run. Rule change: `gemma-4-12b-it-qat-w4a16-ct` is an allowed base model. Local measurement:
the 12B (model_12b, Kaggle model version 1, architecture Gemma4UnifiedForConditionalGeneration) is served under the 31B's
served name so the unchanged agent_e10 and harness run on it (our local swegemma has no 12B alias; Kaggle's page lists it).
Risk: vLLM 0.19.1 has no native class for this architecture; it may fall back to the Transformers backend (slower than
Kaggle) or fail. If serving fails, E14 is "blocked: needs a newer vLLM", logged, and the 31B server is restored.

Questions and predictions (OOD-45 × 1 + rb64 × 1, e10 prompt):
1. Speed: mean time per task ≤ 0.6 × the 31B e10 runs of the same sets (needed for ≥ 1.6 attempts in the same time).
2. Quality: solved ≥ 0.75 × 31B e10 (OOD 39.5/45 → ≥ 30; rb64 22/64 → ≥ 16.5).
If both hold, P2 is alive: design a 12B best-of-2/3 with the E10 check as selector. If quality < 0.6 × 31B, P2 is dead
for the main track (note for the E4B/E2B small-model bonus).

## Addendum c (2026-10-31, before the quality runs): speed cannot be measured locally
E14b's first attempt: neither model served on vLLM 0.32 (flashinfer sampler JIT needs nvcc). With
VLLM_USE_FLASHINFER_SAMPLER=0 both serve. Decode on the RTX 5090, same stack, graph mode: 12B 69 tok/s vs 31B 57.7
(49 each with 3 streams): only ~1.2×. The 5090 (1.8 TB/s) is overhead-bound at batch 1-4; Kaggle's L4 (300 GB/s each,
TP4) is bandwidth-bound, where weight size (12B 8.3 GB vs 31B ~2×) sets speed. So **question 1 (speed) is judged
from tokens and calls per task** (both arms log them), with the Kaggle speed ratio taken as an assumption to be
checked by one Kaggle draw, not from local seconds. Question 2 (quality ≥ 0.75 × 31B) stands as written.

## Outcome (2026-11-01): P2 dead for the main track
12B (agent_e10, vLLM 0.32): OOD-45 23/45 vs 31B e10 38.5 (0.60×); rb64 7/64 vs 31B ~23 (0.30×). Quality fails the 0.75
rule by a wide margin, worst on hard tasks. 31B-new control dropped (not needed for this verdict).
