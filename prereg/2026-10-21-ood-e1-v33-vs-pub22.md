# Pre-registration E1: does OOD-45 reproduce the Kaggle ordering? (v33 vs pub22)

Written 2026-10-21 before any agent run on OOD-45.

## Why
Host statement (kb/discussions.md): the hidden set uses repositories that are not in the public 129, and every
hidden task is gold-solvable. Our lineage scored 9, 8, 7, 7, 6 of 58 on Kaggle while dev40 rose; the public
single-agent bundle (pub22) averages ~10/58 on Kaggle but ties v26b on dev40. Hypothesis **H1: dev40 is
unrepresentative of the hidden repos; on unseen repos the single thinking agent is genuinely better.**
Alternative **H0: the Kaggle gap is draw noise** (5 of our draws, mean 7.4, vs many draws of pub22, ~10).

## Set-up
- Tasks: OOD-45 (`dev_sets/ood45.txt`), rewritten statements, Docker sandbox, per-repo wheels,
  one task per process, 3 processes at once (`scripts/run_ood.sh`). Only tasks that pass gold and fail empty
  are scored (from `results/ood-gold-20261021`, `results/ood-empty-20261021`).
- Arms: `agent_v33` (explorer → planner → finisher chain, root thinking off, 5 min, 80 calls, 30 s command
  timeout) and `agent_pub22` (public single agent, thinking 4096 + include_thoughts, 8 min, 28 calls, 240 s).
  Both unchanged. Two passes each, interleaved v33 r1, pub22 r1, v33 r2, pub22 r2.

## Predictions (H1)
- pub22 − v33 ≥ +2.0 tasks per pass on the scorable OOD tasks, one-sided within-task permutation p ≤ 0.2.
  (Kaggle gap ≈ 2.6/58 = 4.5 points ≈ 2 of 45.)
- Absolute: v33 between 10% and 35% of scorable tasks (Kaggle 6-9/58 = 10-16%, OOD tasks are small and
  their statements are clear, so higher than Kaggle).
- Mechanism counters reported for both arms: empty-patch rate, wrong-patch rate, median time to first edit,
  timeouts.
## Decision
- If H1 holds: OOD becomes the primary local metric and the single thinking agent the new base. The next
  designs (adaptive thinking) are built on pub22's shape and tested on OOD.
- If pub22 ≤ v33 + 0.5: H0 is favoured; OOD still replaces dev40 as the main metric (it matches the hidden
  set's construction), and the base stays v33.
- In between: two more passes each before deciding.

## Outcome (2026-10-21 03:36, 2 passes each, 45 scorable tasks)
- **pub22 - v33 = +6.00 tasks per pass, one-sided permutation p = 0.004. H1 holds** (predicted >= +2.0, p <= 0.2).
- v33 33.5/45 (74%, repo macro 80%), empty 4/90, wrong 19/90. pub22 39.5/45 (88%, macro 91%), empty 2/90,
  wrong 9/90. v33 is better on 3 tasks by half a task each; pub22 on 14.
- **Absolute prediction failed**: v33 74%, not 10-35%. OOD-45 statements are clear user reports with an executed
  reproduction; the hidden set was filtered by a strong model and is far harder for Gemma (pub22 ~17% on Kaggle).
  OOD-45 orders agents in the Kaggle direction but sits near the ceiling.
- Pacing: pub22 7.8 s per model call locally at 3 processes vs 8.7 s reported for Kaggle, so local budgets bind
  about as they would there. pub22's original statements are not a harder variant: 43/45 leak the fix.
- Decision (as registered): OOD-45 becomes the primary local metric, pub22's single thinking agent the base.
  Next: E2 (`2026-10-21-e2-budget-and-spec-verify.md`).
